## How this queue works

- One row = one смысловая единица = the seed for one Threads post (the doc's
  original plan mixes video and text; this repo only ships Threads text, so
  every unit becomes a post regardless of the doc's video/text hint).
- Work strictly in row order (1 to 138). On "напиши следующий пост" (or
  equivalent), take the row at `next_index`, draft the post from it, then
  advance `next_index` by 1 (by 2 for a merged pair, see below).
- **Pairs**: "Озвучивание возражений" immediately followed by "Снятие
  возражений" for the same pain are ONE post, per the source doc's own rule
  ("Пары делаем одним роликом"). Pairs: (4,5), (38,39), (92,93), (107,108).
  Consuming a pair advances `next_index` past both rows at once.
- **Blocked rows** (`после кейсов` / `опрос`): the source doc says these need
  real data from actual first users and must not be published invented.
  Skip them when advancing the cursor - do not consume a post slot on them -
  and log them in the Waiting list below. Revisit once the founder supplies
  the real case/survey material, then write the post and cross it off
  Waiting (it does not need to wait for its turn in the main cursor again).
- **Cycling**: when `next_index` passes 138, wrap to 1 and bump `cycle`. On a
  repeat cycle, do NOT reuse the previous angle/formula/wording for that row
  - check the Log below for what ran last time on that index and take a
    different formula, hook, or specific detail this time.
- Every post still goes through the normal pipeline regardless of source:
  pick a threads-post-writer formula, run threads-humanizer, close with the
  standing free-trial CTA from voice-profile.md section 4.
- **Every post ships with an image ТЗ** (founder's standing rule, 2026-10-01)
  - square 1:1, in the established brand style from voice-profile.md section
    6 (palette, Egyptian-luxury style rules, the mandatory cat anatomy and
    left-ear-only earring clauses). Not optional, not only on request - every
    single post gets one, scene tailored to that post's specific unit.
